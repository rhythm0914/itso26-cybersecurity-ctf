Flag hash generator

Tools for the organiser

1. Type the flag

2. Copy the hash


          

          

            
          

        

      


      

        
How it works

        

          The site never stores a flag in clear text. For every answer the browser
          calculates
        

        
hash = SHA256( salt + "::" + normalised_answer )

        

          and compares that hash with the one stored in js/challenges.js. The
          salt lives in js/config.js and is shown in the top right corner of
          this page - both files must use the same salt.
        

        
    
          
  • Normal challengesThe answer is trimmed and compared case sensitively.
    • 
          
  • Trivia answersThe answer is trimmed, lower cased and commas, dots, colons and question marks are removed.
    • 
          
  • Extra accepted answersGenerate one hash per alternative and collect them in the altHashes array of the challenge.
    • 
        

        

          Never publish the plain flag. If you change the salt in
          js/config.js you have to regenerate every hash - run
          python3 tools/generate_files.py --verify to check them.
