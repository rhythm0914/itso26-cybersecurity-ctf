Progress backup

Export writes a JSON file with your team, the clock, every solved challenge, every hint and every attempt. Import restores it on another machine or in another browser. The Reset everything button appears in practice mode (js/config.js: practiceMode: true); in exam simulation mode you can still clear the data with the browser's "clear site data" option.

Published leaderboard

The rival teams come from data/scoreboard.json. As the organiser you can edit that file by hand (or data/scoreboard.js when the site is opened straight from a file, where the browser blocks JSON fetches). Each entry looks like: 

{
  "name": "Byte Bandits",
  "school": "Northgate Technical College",
  "score": 720,
  "solved": 11,
  "lastSolve": "2026-10-20T09:47:00Z"
}
